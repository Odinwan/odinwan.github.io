# Sound effect credits

Every file in this folder is derived from a recording released under
**Creative Commons Zero 1.0 (CC0, public-domain dedication)** —
<https://creativecommons.org/publicdomain/zero/1.0/>. No attribution is
required; this list exists as a record of where each sound came from and of the
licence shown by the source.

How the licence was checked (2026-11-20):

- **Freesound** — each sound's own page (`freesound.org/people/<user>/sounds/<id>/`)
  was fetched and its licence link read. All entries below showed
  "Creative Commons 0" linking to `http://creativecommons.org/publicdomain/zero/1.0/`.
  The audio was taken from the publicly served high-quality MP3 preview of that
  same sound (`cdn.freesound.org/previews/.../<id>_<userid>-hq.mp3`); no account
  or API key was used.
- **Kenney "RPG Audio"** — downloaded from <https://kenney.nl/assets/rpg-audio>.
  The archive's `License.txt` reads: "License (Creative Commons Zero, CC0)
  http://creativecommons.org/publicdomain/zero/1.0/ — You may use these assets
  in personal and commercial projects. Credit (Kenney or www.kenney.nl) would be
  nice but is not mandatory."

All files were trimmed, converted to mono 44.1 kHz MP3 (96 kbps), level-matched
and given short fades. Files marked "mix" combine several sources.
