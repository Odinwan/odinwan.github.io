# CV sources

The three PDFs in `public/cv/` are printed from these HTML files with headless Chrome
(`page.pdf({ preferCSSPageSize: true, printBackground: true })`), then given a proper
title and author in the PDF metadata. Edit the HTML, print again, replace the PDFs.
